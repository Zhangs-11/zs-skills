# dating-chat-coach

> 不知道“她这句话到底什么意思”，也不必靠套路和猜心硬撑下一句。

dating-chat-coach 面向相亲和线上认识两种场景，帮助你判断交流阶段、理解兴趣信号、起草自然回复，并在合适时机转微信或提出具体邀约。核心是尊重、真诚和双向筛选，不是操控对方。

## 安装

```bash
npx skills add Zhangs-11/zs-skills --skill dating-chat-coach
```

## 你可以这样说

- “相亲对象刚加微信，第一句怎么说？”
- “她说‘最近有点忙’，我怎么回比较自然？”
- “聊了三天，现在适合约见面吗？”
- “这个账号有哪些诈骗信号？见面要注意什么？”

## 回答会包含

- 当前处于破冰、熟悉、升温还是邀约阶段
- 1–3 条可直接发送、符合上下文的消息草案
- 对方兴趣信号与不确定性的区分
- 下一步节奏，以及需要停止推进的边界

## 边界与安全

- 不提供欺骗、施压、骚扰、PUA 或绕过明确拒绝的话术。
- 两次被明确拒绝后停止邀约；低回应不等于同意。
- 首次见面优先公开场所，并向可信联系人同步行程。
- 涉及转账、投资、借款或异常身份信息时，优先做诈骗核验。

## Troubleshooting

| 问题 | 解决方法 |
|---|---|
| 建议太泛 | 提供最近 5–10 轮对话、认识渠道和你想达到的目标 |
| 不确定对方是否有兴趣 | 让 skill 区分事实信号、合理推断和未知，不做读心结论 |
| 对方已明确拒绝 | 尊重边界，停止推进，不继续设计挽回话术 |

完整方法与安全规则见 [SKILL.md](SKILL.md) 和 [reference.md](reference.md)。
