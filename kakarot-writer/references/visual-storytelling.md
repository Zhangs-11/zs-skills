# 公众号图文设计

用于公众号解释、教程、方法、对比类文章，以及明确要求图解或减少阅读负担的内容。图是表达选择，不是交付配额；先判断是否需要图，再选择形式和工具。以下尺寸是编辑起点，不是微信官方限制或传播效果保证。

## 先确定读者来拿什么

先说清文章的主角是一个观点、一份可复制材料，还是需要理解的机制。若任务是短引入加提示词，正文围绕这份材料展开，不为展示作者工作量补上配置复盘、模块树和流程图。纯叙事也不强制图解。

逐节只确定读者的问题、必要信息及最省力的表达。文字已经能讲清的短判断直接写；需要证明来源时放真实截图；空间、数量、变化或关系确实有助于理解时才画图。图文分工先于 human-writing 正文生成，去掉图仍不损失理解的地方可以零解释图。

用户要求轻阅读时，篇幅由核心交付决定，不先凑字数。图中文字也计入负担；图片不能成为藏长段落的容器。原生提示词与重点区块按 delivery.md 排版，不转成长图。

## 先做视觉取舍，再选工具

需要原创解释图时，先查看与本次信息关系相近的优秀成品，而不只读绘图库 README。按需选少量参考，实际看图，确定各自如何处理主体、视觉焦点、标签、留白和阅读顺序；借鉴机制，不复制品牌资产、配色外观或装饰。无需每次重复调研已有且适用的样本。

每图确定一个读者应该先看见的对象或变化。用位置、尺度、分组、颜色或明暗承担信息，让次要说明退后；颜色和线型要有一致含义，并配文字说明。标签贴近解释对象，缩短视线来回寻找的距离。先简化内容和层级，最后才调圆角、阴影等表面样式。

不能默认把每句话塞进等大的色块，再用箭头串起来；也不强制不用方框。结构本身就是重点时，克制的方框和连线仍然合适。检查图是否有明确主次，而不只是「没有溢出」。

| 真正需要表达的关系 | 合适的起点 |
|---|---|
| 组成与归属 | 空间分组、局部高亮或结构示意；包含与调用不能混画 |
| 前后差异 | 同对象、同尺度的上下对照，突出变化而非重写两遍说明 |
| 次序与分支 | 只展示关键路径的流程图，标明条件与出口 |
| 角色交接与等待 | 泳道或时序图；只有责任归属本身重要时才使用 |
| 数量与分布 | 数据图；单位、基线与来源完整，没有数据不画统计图 |
| 抽象观点或原文证据 | 短文字或真实截图优先；有必要才增加概念插画，不能冒充证据 |

Mermaid 可用于关系草图或标准技术链路，默认渲染主题不等于公众号设计成品；D2 是复杂分组的备选。需要控制视觉层级和中文排版时，用可编辑 SVG 或 HTML/CSS。选择来自表达需要，不为一张图安装整套产品，也不把工具当成风格。

## 手机阅读与验收

正文优先单列向下阅读，不依赖横向滑动、放大或交互才能理解。复杂图先拆成主关系与局部，不靠不断增高画布和缩字解决。网页参考中的交互只借鉴讲解顺序，公众号要改为可独立理解的静态状态。

正文图可从 900～1080 px 宽的 PNG 开始，保留可编辑源；母稿引用渲染图片，不交付等待平台执行的 Mermaid 代码。用 360/390 px 视口检查整篇及实际正文边距，主要标签显示后以约 14～16 CSS px 为起点；按「源字体 × 显示宽度 ÷ 源图宽度」换算，高分辨率不能补救小字。

终审同时看内容和成品：第一眼能否找到重点，位置与连线是否表达真实关系，次要说明是否抢眼，手机下是否清晰。图旁只补原因、边界和必要摘要，不逐项复述；alt、关键风险、链接和可复制参数仍以文字保留。发现内容不需要图就去掉，不为完成图数保留它。

沿一个明确案例核对图义，再实际看窄屏渲染；这属于作品验收，不用文档关键词测试代替。概念图不是运行记录，规则推演不是实测。公众号后台未验收时只报告本地预览结果，交付链接另按 delivery.md 验证。

## 成品参考

以下样本已查看实际画面，按相近问题参考，不设为每篇必读：

- [Apple M4](https://www.apple.com/newsroom/2024/05/apple-introduces-m4-chip/)：以具体主体为中心，局部高亮与附近标注解释当前部件；不照搬其桌面小字和横版构图。
- [Distill：Attention and Augmented RNNs](https://distill.pub/2016/augmented-rnns/)：用一致的对象、颜色权重和局部连线逐步讲机制；方框有语义，不是段落外壳。
- [Bartosz Ciechanowski：GPS](https://ciechanow.ski/gps/)：用空间场景与分步呈现降低复杂度；交互不能原样搬进公众号。
- [W3C Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)：减少双向滚动的依据；本工作流窄屏检查不等于 WCAG 合规认证。
