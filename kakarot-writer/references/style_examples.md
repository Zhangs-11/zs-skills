# 两篇文章提供的写法证据

这份文件记录可迁移的写作机制，不提供固定句库。示例只保留短句，不复制整段文章。

## 经验文

主要样本是《实习了两年的应届生，想和刚入职的你聊聊，新公司第一个月该怎么过？》。

### 先交代位置，再给建议

文章先说明累计实习两年、经验主要来自开发岗，又承认很多地方处理得不好。这个顺序降低的不是语气，而是建议的傲慢感。

可迁移原则：给建议前，让读者知道经验从哪里来、适用到哪里，不需要把作者包装成成功人士。

### 一个建议同时写动作、理由和例外

“问问题”不是一句“大胆提问”。文章区分大会议、小会、带教窗口、同事忙碌和紧急任务，并补上作者自己踩过的坑。

可迁移原则：方法文的篇幅来自真实条件和过程，不来自把结论解释五遍。

### 技术知识顺着工作问题出现

文章讲新人如何使用 Claude Code 时，引入《人月神话》的外科手术式团队。它解释了为什么新人也需要承担方向和验收，而不是单纯展示读过一本书。

可迁移原则：知识必须改变读者对当前问题的理解。

### 回环有新的含义

开头是毕业季的学位服，结尾回到几个月后的工位。前后是同一批年轻人，但读者已经知道进入公司后会遇到什么。

可迁移原则：回环不是重复意象，而是让同一事物带着正文产生的新含义回来。

## 个人与公共议题

补充样本是《二十多岁，为什么我们活成了“成年的未成年人”》。

### 从自己的处境进入

文章先交代作者二十二岁、即将毕业、做 AI 开发，同时也迷茫和焦虑，再把问题扩展到同龄人的过渡状态。

可迁移原则：公共议题先说明作者为什么被它碰到，不要直接代表所有人发言。

### 概念成为文章骨架

“奥德赛时期”解释了成年、稳定和社会时钟之间的落差，因此可以贯穿文章。它不是临时贴在结尾的典故。

可迁移原则：一个概念只有在能组织多段真实材料时，才值得成为文章锚点。

## 反例

### 表演式口语

不推荐为了像真人而把“卧槽”“尼玛”“兄弟们”按固定频率放进文章。两篇样本真正稳定的特点是说明处境、承认边界和给出细节，不是粗口密度。

### 虚构人物画像

不推荐从“1000 个已付款”直接写出一个四五线城市学生的出租屋、工资和晚餐。这些细节没有来源时，只会把同理心写成假证据。

### 强行升华

正文没有持续处理时代尺度时，不要突然在最后召唤“浪潮”“新时代”和“历史转折”。具体判断已经成立，就停在具体判断上。

### 机械禁句

“不是……而是……”并不天然是 AI 味。经验文样本中，它经常负责澄清误解。真正需要删除的是没有事实差异、只为了制造反转的翻案句。
