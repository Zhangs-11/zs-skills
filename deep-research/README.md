# deep-research

> 沿历史演化和横向对比两条轴，研究一个陌生对象，并让关键结论都能追溯。

deep-research 适合系统研究产品、公司、人物、技术、行业、制度或事件。它不会把时间线写成流水账，也不会只列一张竞品功能表，而是解释历史选择怎样变成今天的能力与包袱、用户为什么选择或放弃不同方案，以及哪些事实真正支撑未来判断。

## 安装

```bash
npx skills add Zhangs-11/zs-skills --skill deep-research
```

## 你可以这样说

- “帮我系统研究 AI 编程 Agent，既讲发展史，也比较现在的主要产品。”
- “横向纵向分析一下这家公司，重要结论都给一手来源和日期。”
- “我想快速搞懂这个陌生行业，给我时间线、对比表和未来三条路径。”
- “把这份行业观点里的事实、推断和价值判断拆开核查。”

## 默认研究结构

1. 固定研究对象、截止时间、用途和真正要做的判断。
2. 用关键转折解释历史形成的能力、路径依赖和包袱。
3. 选择真实替代品，以统一维度比较并解释选择与放弃原因。
4. 将两条轴合并，推导带前提、信号和反证的未来路径。
5. 把关键主张拆成事实、推断和价值判断，分别核验。

## 边界

- 简单事实查询、单篇摘要和当天资讯简报不应使用本 Skill。
- 优先使用官方文档、原始数据、论文、财报、规范和完整访谈；二手文章主要用于发现线索。
- 用户没有要求文件时直接在对话交付，不会为了流程自动向仓库写报告。
- 报告长度服从问题需要，不默认生成一万字以上长文。
