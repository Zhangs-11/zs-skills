# storage-analyzer

> 磁盘满了时，最危险的不是找不到大文件，而是误删了真正重要的东西。

storage-analyzer 在 macOS 或 Windows 上做只读扫描，找出空间大户，并把候选项分成“可清理、需判断、谨慎处理”三级。它会生成可折叠的 HTML 报告、解释风险并给出处置方案；扫描阶段不会删除任何文件。

## 安装

```bash
npx skills add Zhangs-11/zs-skills --skill storage-analyzer
```

## 你可以这样说

- “电脑空间不够，帮我做一次存储分析。”
- “看看 C 盘哪些东西最占地方。”
- “扫描一下磁盘，先只给清理建议，不要删除。”

## 你会得到

- 按目录、文件类型和可回收来源整理的空间分布
- 🟢 可自动清理 / 🟡 需人工判断 / 🔴 谨慎清理三级建议
- 可复制的清理命令与风险解释
- 本地交互式 HTML 报告

## 安全边界

- 扫描只运行读取、统计和元信息命令。
- 报告中的“可释放空间”是估算值。
- 删除命令默认只展示；移动到废纸篓或直接删除前必须再次获得明确确认。
- 用户明确说的是 RAM/运行内存占用时，不属于本 skill。

## 前置条件

- [ ] Python 3 可用：`python3 --version`。
- [ ] 当前用户对待扫描目录有读取权限。
- [ ] 扫描整机可能耗时较长；可先指定一个磁盘或目录缩小范围。

## Troubleshooting

| 问题 | 解决方法 |
|---|---|
| `Permission denied` | 报告会标注未扫描路径；按需授予终端完全磁盘访问权限后重试 |
| 报告数字与系统设置不同 | 文件系统快照、缓存和统计口径可能不同，按估算处理 |
| 用户想直接删除 | 先列出精确目标和可恢复方式，获得明确确认后再执行 |

完整工作流见 [SKILL.md](SKILL.md)。
