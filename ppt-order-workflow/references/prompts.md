# AI PPT 提示词

这些提示词根据原文章流程改写，并扩展了核对和交付要求。方括号替换为本单信息；没有确认的信息写“待确认”。按实际工具能力调整，不把模型回答当作验收证据。

使用前先核对本单的店铺规则和客户授权。涉及 AI 的提示词、图片生成与重建仅在本单允许的范围内使用；当前合作店铺的订单还须遵守主流程中的交付与 AI 规则。

## 1. 理解客户需求

```text
你是负责 PPT 静态美化的设计师。请先阅读我上传的材料，暂时不要生成图片。

材料说明：客户需求及沟通记录 [文件]；原 PPT 导出的 PDF [文件]；重点页面截图及页码 [文件、页码]；参考风格 [文件]；交付要求 [页数、比例、截止时间、可编辑范围]。

请整理：（1）客户需求和交付边界；（2）原稿总页数，以及每页标题和主要内容；（3）参考风格的配色、字体、版式和元素特征；（4）无法看清、互相矛盾或需要客户确认的信息；（5）需要特别核对的数字、单位、图表和专有名称。

严格保留原文和数据。无法识别的地方标注“待确认”，不要自行补写或猜测。等我确认后再进行设计。
```

## 2. 生成六页缩略预览

```text
根据已确认的客户需求、原稿和参考图，设计第 [页码] 页到第 [页码] 页的视觉方案。
请在一张图中展示这几页各自的缩略预览，每格代表一页，清楚标出原稿页码。总页数不足六页时按实际页数制作。
要求：整套页面的配色、字体感觉、标题层级和组件风格保持统一；遵守 [特殊要求]；保留各页已有内容和数据，不要跨页混用。预览只用于确认布局，文字看不清的部分请标记，后续单页仍需核对。
```

## 3. 调整单页设计

```text
请只修改第 [页码] 页的 [具体位置]：[明确的修改动作]。
其余页面和该页未提及的配色、版式、文字与数据保持不变。
先给我更新后的预览，列出你调整的内容，不要扩展到其他页面。
```

## 4. 生成高清样稿

```text
请按照已确认的缩略预览，分别生成第 [页码列表] 页的完整高清页面图。
每页单独生成一张 [16:9 或实际比例] 的图片，保持标题、字体风格、配色和组件一致。不要裁切放大缩略图。逐页对照原稿，保留原文、数字、单位和专有名称；看不清的内容先标出，等待我补充。
```

## 5. 生成剩余页面

```text
样稿已确认。已完成页码：[列表]；本批需要制作的页码：[列表]。
沿用已确认的页面风格，先生成本批各页的缩略预览，并标明原稿页码。每张预览图最多展示六页。不得遗漏、重复、混淆页码，也不得修改原始文字和数据。
我确认预览后，再将每页分别生成完整高清图。
```

## 6. 还原为可编辑 PPTX

先按 PPT Rebuilder King 当前发行说明配置项目，在项目内附上一张单页高清图。

```text
请读取本项目上传的 PPT Rebuilder King 运行 ZIP，遵循项目指令和压缩包内的工作流程，重建这张第 [页码] 页的图片，并提供可下载的 PPTX。
普通文字需要独立编辑；形状、图片和图表请说明哪些能够分别选择和修改。不得把图片中的文字直接当成可编辑文本。无法原生还原或不确定的部分，请逐项列出。
```

## 7. 交付前审查

```text
我会提供原稿、逐页预览和最终 PPTX。请逐页核对总页数、顺序、标题、正文、数字、单位、专有名称及内容遗漏。
输出“页码 / 原稿内容 / 成品内容 / 差异 / 需要人工确认的项目”。
对于你无法实际检查的文字编辑、图表数据、Office 兼容或放映效果，请写“未验证”，不要假定通过。
```

## 8. 整理客户修改意见

```text
根据以下客户反馈，整理修改清单：按页码、具体位置、修改动作、是否改变原文、是否可能超出约定范围分类。
不明确的要求列为待确认，先不要补充客户没有提出的要求。
客户反馈：[粘贴反馈]
本单已约定的修改范围：[粘贴约定]
```
