# AI PPT 美化接单

想接 PPT 美化订单，却不清楚怎么找店铺、确认需求和交付可编辑文件？这个 Skill 帮你从练习作品走到报价、样稿、验收和结算，并提供八组可复制提示词。

```bash
npx skills add Zhangs-11/zs-skills --skill ppt-order-workflow
```

你可以直接说：

- “帮我准备一套 PPT 样稿，拿去找店铺合作。”
- “根据客户的原稿和参考图，列出 PPT 美化步骤和提示词。”
- “帮我核对这个订单的报价、可编辑要求和交付清单。”

Skill 按当前阶段提供订单信息卡、八组提示词、沟通草稿及有效时薪算法。需要真正制作文件时，使用运行环境中的演示文稿工具；可选用 PPT Rebuilder King 将单页图片重建为 PPTX。

## 使用前确认

- [ ] 安装 Node.js 后运行 `node --version` 和 `npx --version`，再执行安装命令；新开 Agent 会话以加载 Skill。
- [ ] 制作 PPTX 时，准备支持生成及检查演示文稿的工具，并使用 PowerPoint 或 WPS 验收客户要求的编辑能力。
- [ ] 使用 PPT Rebuilder King 时，参照其[官方仓库](https://github.com/frederick-kk/ppt-rebuilder-king)配置当前运行包和 ChatGPT 项目指令；账号能力和费用以实际情况为准。
- [ ] 上传客户资料前先取得客户对第三方 AI 的许可；联系店铺、发送样稿和交付文件需要用户明确授权。

## 常见问题

| 问题 | 处理方法 |
|---|---|
| 安装后没有触发 | 新开会话，明确说“使用 ppt-order-workflow 帮我准备 PPT 美化接单”。 |
| 生成的是图片，客户要求可编辑 | 先约定文字、形状和图表数据分别需要什么编辑能力；重建后实际修改并保存验证。 |
| 重建失败或背景仍含文字 | 保留现有结果，检查工具提示和当前版本的重试要求；必要时先取得明确授权，再按工具规则操作。 |
| 不知道是否值得接单 | 收集实际到手金额、直接成本和完整工时，计算有效时薪；结算规则不清时先确认。 |

## 来源与限制

流程参考[小鱼 Fred 的文章](https://x.com/Frederickkk07/status/2115059764887720204)，图片重建可选用作者的 [PPT Rebuilder King](https://github.com/frederick-kk/ppt-rebuilder-king)。提示词根据文章思路改写及扩展。一次实际试用中，图表页背景重试后仍不合格，不能据此承诺每页都可重建成功。报价和收入取决于实际合作条件，案例展示应真实说明背景。
