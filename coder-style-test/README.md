# coder-style-test

> 同样是写代码，有人先画图纸，有人先跑起来；有人把 AI 当助手，有人把 AI 当同事。

coder-style-test 在对话里出 20 道情景选择题，从起手方式、完成标准、和 AI 的分工、协作习惯四个方面，测出你在 AI 时代写代码的风格。一共 16 种类型，比如钟表匠、规格作者、一人军团、黑客、冲浪手。题目和计分与网页版 [编程风格测试](https://kakarot-index.kakarot-space.workers.dev/coder-style/) 完全一致。

## 安装

```bash
npx skills add Zhangs-11/zs-skills --skill coder-style-test
```

## 你可以这样说

- “测测我的编程风格。”
- “我是什么类型的程序员？出题吧。”
- “一道一道问我，做一次编程风格测试。”

## 你会得到

- 四个字母的风格代码、类型名称和一句话描述
- 四个方面各自的倾向和比例
- 你的强项、要留意的地方、和 Agent 合作的建议
- 最互补的搭档类型
- 可以分享给朋友的网页版结果链接

## 前置条件

- [ ] Python 3 可用：`python3 --version`。计分脚本只用标准库。

## Troubleshooting

| 问题 | 解决方法 |
|---|---|
| 脚本提示答案数量不对 | 按题号顺序补齐 20 个 A 或 B 后重新计分 |
| 想看全部 16 种类型 | 直接问，或者打开网页版结果页的最后一部分 |

完整工作流见 [SKILL.md](SKILL.md)。
