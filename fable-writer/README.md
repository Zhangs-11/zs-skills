# fable-writer

> 抽象概念背定义很快，真正形成直觉却很难。

fable-writer 用一个具体场景、一到三名角色和清晰转折，把经济学、物理学、社会学或哲学概念包进一则精炼寓言。正文不直接点破术语，结尾再给出概念解析和检验问题，帮助读者确认自己是否真的理解。

## 安装

```bash
npx skills add Zhangs-11/zs-skills --skill fable-writer
```

## 你可以这样说

- “用寓言解释沉没成本。”
- “写个故事讲明白幸存者偏差。”
- “把网络效应写成一则 800 字以内的寓言。”

## 输出结构

1. 寓言正文：不出现概念名称，不让角色充当解说员。
2. 概念解析：说明情节如何对应机制和边界。
3. 检验问题：用新情境检查读者能否迁移理解。

## 边界

- 适合解释一个明确概念，不适合代写事实报道或长篇小说。
- skill 内置意象与套路黑名单，优先具体、新鲜的场景。
- 用户没有提供明确概念时，会先帮助缩小主题。

## Troubleshooting

| 问题 | 解决方法 |
|---|---|
| 故事像定义换皮 | 要求让冲突、选择和结果承载机制，删掉解释性对白 |
| 概念过大 | 缩小到一个原理、效应或因果关系 |
| 寓意太隐晦 | 保持正文间接表达，但在“概念解析”中明确映射 |
