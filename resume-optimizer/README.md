# resume-optimizer — 程序员简历优化 Skill

以资深技术面试官的视角，帮开发者写出能拿到面试邀约的简历。

## 能做什么

- **从零写简历**：给出经历素材，按标准结构产出完整简历
- **整体优化**：现有简历全文重组、逐模块打磨
- **单模块打磨**：只改项目经验、专业技能等某一块
- **简历评审**：指出亮点、问题和逐条修改建议

## 核心特点

- **绝不编造**：只重组和提炼你给的真实信息，缺什么会直接问你，不脑补经历、项目和数据
- **按 JD 逐项对证据**：先把岗位必须项、加分项与简历事实对应起来，明确直接匹配、可迁移证据、缺口和未知
- **面向筛选场景**：按「简历是广告不是档案」的思路写，每一行都为拿到面试服务
- **按年限分层**：3 年 / 5 年 / 8 年经验的简历侧重点完全不同，规范里分别定义
- **成果导向但不造数字**：有真实数据就量化；没有数据就写清规模、难度、职责边界和可验证结果

## 安装

```bash
npx skills add Zhangs-11/zs-skills --skill resume-optimizer
```

无额外依赖，不需要 API Key。安装后重新启动或新开一次 Claude Code / Codex 会话。

## 怎么用

安装后直接对 Claude 说：

- "帮我写一份简历，我的经历是……"
- "优化一下我的简历"（附上简历内容或文件）
- "帮我把项目经验这块改好一点"
- "按这份 JD 优化我的简历，先列出每项要求对应的真实证据和缺口，不要硬塞关键词"
- "以面试官视角评审下这份简历"

## 风险边界

- 不编造工作、项目、教育、技术栈或数据；信息缺口会先集中提问。
- 面向具体岗位优化时，最好同时提供岗位描述与当前简历；JD 只是目标，不是候选人事实来源。
- 输出仍需本人逐项核对，确保每一条都能在面试中解释和举证。

## Troubleshooting

| 问题 | 解决方法 |
|---|---|
| 建议过于通用 | 补充目标岗位、工作年限和当前简历 |
| 缺少量化成果 | 提供真实基线、规模和结果；没有数据时不编数字 |
| 排版文件无法直接修改 | 提供 `.docx`、PDF 或纯文本，并明确希望保留的版式 |
