# ai-hot-picker

> 热点很多，真正适合今天写、又和你的受众有关的选题很少。

ai-hot-picker 会读取 AI HOT 的当日聚合结果，先识别多信源共同报道的大事件，再从传播性、相关性和可写性出发推荐公众号或社交媒体选题。它给出的不是新闻搬运清单，而是可直接进入创作的角度。

## 安装

```bash
npx skills add Zhangs-11/zs-skills --skill ai-hot-picker
```

## 你可以这样说

- “今天 AI 圈有什么适合公众号写的？”
- “从今日热点里挑 3 个选题，说明为什么值得写。”
- “找一个适合发推的 AI 话题。”
- “用第 2 个选题继续写成长文。”

## 你会得到

- 多信源聚焦的当日大事件
- 带来源链接的候选选题表
- 每个选题的推荐理由、切入角度和风险提醒
- 可继续交给 `kakarot-writer` 的写作方向

## 前置条件与边界

- [ ] 能访问 `aihot.virxact.com` 的公开接口；不需要 API Key。
- [ ] 热点与评分会随时间变化，输出应保留来源链接和数据时间。
- [ ] 新闻事实仍需回到原始来源核验，不把聚合摘要当成唯一证据。

## Troubleshooting

| 问题 | 解决方法 |
|---|---|
| 返回 `error` 或没有数据 | 稍后重试，并检查网络与 AI HOT 服务状态 |
| 只得到资讯摘要，没有选题建议 | 明确说“挑选题”并说明平台、受众或账号方向 |
| 推荐与账号不匹配 | 补充受众、内容定位和不想写的主题 |

完整执行规则见 [SKILL.md](SKILL.md)。
