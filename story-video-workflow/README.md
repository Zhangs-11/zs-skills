# 历史人物故事短视频

从可核实的历史资料制作人物故事视频，并在需要时核对视频号带货权限、选品和实际佣金。本 Skill 管理创作和带货步骤；生成视频时可配合原作者的 Story Studio。

```bash
npx skills add Zhangs-11/zs-skills --skill story-video-workflow
```

可以直接说：

- “只写一篇林巧稚的人物故事口播稿，附上事实来源。”
- “用这段配音制作历史故事的分镜、图片和剪映草稿。”
- “帮我查看视频号能不能推广图书，整理实际费用和佣金。”

## 使用前确认

- [ ] 安装 Node.js 后运行 `node --version` 和 `npx --version`，执行上面的安装命令；在新的 Codex 会话中使用。
- [ ] 需要使用 Story Studio 的配音、转录或剪映草稿时，按[原项目](https://github.com/konlu/story-studio)说明安装并核验所需组件。语音和生图服务可能收费。
- [ ] 使用他人声音、音乐、图书内容或图片前，确认相应授权。发布 AI 内容时遵循平台的标识要求。
- [ ] 带货前检查实际视频号权限、商品、佣金和结算条件；创建小店、支付及发布由用户明确授权。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 安装后没有触发 | 新开会话，明确说“使用 story-video-workflow”。 |
| 只有文案，需要配音和分镜 | 提供本人录音或选择有授权的音色；用最终音频制作并检查时间标记。 |
| Mac 上生成了草稿但剪映没有显示 | 核对剪映版本、草稿位置和素材；只有实际打开并预览后才能确认可用。 |
| 已有公众号带货账号，但视频号不能挂商品 | 分别检查视频号绑定和短视频带货权限，按后台显示的条件处理。 |
