# 历史人物故事短视频工作流

根据用户指定的阶段，协助制作历史或真实人物故事短视频，以及按需核对视频号带货路径。不要把视频播放量、商品成交额或文章作者的案例当作用户的佣金收入。选题、脚本、视频制作、账号权限和商品成交分别检查；用户只要求其中一项时，只执行该项。

## 视频制作

1. 确认目标平台、人物或主题、时长以及交付范围。用户已有素材或已经明确选择时直接使用，缺少的普通创作参数可以按合理默认值处理。仅需要文案时，不创建音频、图片或工程。
2. 从可核验的史料、权威传记或其他可靠来源整理时间线和事实表。事实、推断和戏剧化表达分开；没有证据的具体数字、引语、心理活动和细节不要写成事实。设计吸引人的开头和故事推进，但不改变事实含义。按请求交付选题、口播稿或事实表，并附可追溯来源。
3. 完成文稿后，根据用户选择使用本人录音、已获授权的音色或语音服务制作配音。核对服务价格、音色权限及实际费用；不要收集或在对话和项目文件中输出密钥。听完整段音频，检查漏字、重复、残音和断句，保留实际检查结果。
4. 使用最终配音生成带时间的转录，核对人名、词语和时间，再按真实时间拆分分镜。为每镜注明口播片段、画面内容和时代依据。画风和输出比例按用户要求或目标平台确定；实际检查生成图片的人物、年龄、服饰、场景和画面与口播的对应关系。AI 图片是生成画面，不应冒充历史原照。
5. 将配音和已核对的图片按分镜导出剪映草稿。默认是否显示字幕遵循用户要求或所用制作工具的实际默认值；需要字幕时检查识别内容与出现时机。检查画面覆盖、素材、切点和声音，实际在目标剪映版本打开、预览并导出后才能称为完成验证。用户要求 MP4 时再生成并检查成片。

上面各阶段可使用原作者的 [Story Studio](https://github.com/konlu/story-studio)：读取已安装的 `story-studio/SKILL.md`，按其模块和当前请求调用实际工具；缺少时先说明需要安装，用户授权后从原仓库安装。此 Skill 不包含 Story Studio 的代码、语料或图片，也不把提示词当作已生成的视频。文案、配音、生图、转录和剪映草稿各自的依赖与授权必须按实际环境检查。

Story Studio 当前项目说明以 Windows 中国剪映桌面版的完整链路为目标；macOS/Linux 能配置依赖或生成文件，不代表草稿已在用户的剪映版本打开。未实际打开和导出时报告未验证，保留已完成的文件。语音服务及生图可能收费，不将“开源免费”理解为制作零成本。

## 视频号带货

用户要求评估带货时，先核对具体账号的主体、当前带货身份、账号状态、可用的短视频带货权限和结算方式。区分商家小店、带货者账号、公众号及视频号；某个账号能进入后台或已有绑定，不能推出视频号已获短视频挂商品权限。条件、保证金及账号切换规则会变化，以平台当前页面和规则为准，不把固定粉丝数写成永久条件。

按用户的内容选择相关商品，核对可推广状态、佣金比例、结算条件、商品资质和退货规则。实际佣金以后台已结算或到账记录为准；记录播放、有效关注、商品点击、订单、退款、制作成本及工时，用实际数据判断是否继续。推广话术应与商品和可核实信息一致，不虚构效果或收益。

用户未明确授权时不创建店铺、绑定或变更账号、不支付保证金、不上架商品、不发布视频，也不联系商家。发表内容时按目标平台当前要求声明和标识 AI 生成内容；第三方素材、声音、音乐及图书内容先核对使用授权。
