# life-designer

> 人生卡住时，问题往往不是缺少一个“正确答案”，而是只允许自己想象一条路。

life-designer 基于人生设计方法，通过多轮对话帮助你看清现状、区分无法改变的重力问题与可以行动的真问题，再设计三个同样值得探索的五年奥德赛计划。最终产出一份带原型行动的人生设计蓝图。

## 安装

```bash
npx skills add Zhangs-11/zs-skills --skill life-designer
```

## 你可以这样说

- “我不知道要不要转行，帮我做一次人生设计。”
- “现在工作没问题，但总觉得不对劲，想系统梳理。”
- “帮我设计三个完全不同的五年版本。”
- “我很迷茫，不知道下一步做什么。”

## 对话会经过

1. 评估工作、健康、娱乐与关系四个维度的现状。
2. 形成工作观与人生观，检查两者是否一致。
3. 追踪心流、能量和长期被忽略的线索。
4. 重构锚问题，生成三个平等而不同的五年计划。
5. 为每条路线设计低成本、可获取新信息的原型行动。

## 边界与安全

- 这是设计与反思工具，不是职业测评，也不会替你做人生决定。
- 急性心理危机、自伤想法或严重心理症状需要尽快联系当地急救、危机热线或专业人士。
- 最终蓝图通常为 8000–12000 字，需要多轮认真回答，不适合“一句话速算命”。

## Troubleshooting

| 问题 | 解决方法 |
|---|---|
| 三个计划看起来只是同一条路换名字 | 强制改变角色、环境、日常结构或价值排序 |
| 计划宏大但无法行动 | 把下一步改成一周内可完成、用于获取信息的原型 |
| 问题无法改变 | 将其标为重力问题，重新设计可控变量 |
